# windows-experience

| Name | Description |
| ---- | ----------- |
| Windows Windows Experience Features Device | Baseline configurations and policies to enable corporate device experience, restrict Windows consumer features, and configure basic lockdown on corporate device. Apply to All Devices (optionally with filters) or Entra ID device groups. |
| Windows Windows Experience Features User | Standard Windows corporate user interface settings to restrict access to consumer features and Microsoft accounts, configures Start menu and Taskbar options, hides public links in the Microsoft Store, etc. Apply to All Users (optionally with filters) or Entra ID user groups. |
