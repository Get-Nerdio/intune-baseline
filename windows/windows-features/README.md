# windows-features

| Name | Description |
| ---- | ----------- |
| Windows Delivery Optimization Device | Windows 10/11 Delivery Optimization settings. Validate Windows Autopilot and application deployment functionality after applying to devices. Apply to All Devices (optionally with filters) or Entra ID device groups. |
| Windows Device Lock Sign-in settings Device | Configurations for device lock and sign-in. Apply to All Devices with optional features, or copy to create settings to apply to different device types |
| Windows Storage Sense settings Device | Storage Sense settings to clear disk space including OneDrive and Downloads folders. Note - this will remove files older than 60 days from the users' Downloads folder and Recycle Bin. Apply to All Devices (optionally with filters) or Entra ID device groups. |
