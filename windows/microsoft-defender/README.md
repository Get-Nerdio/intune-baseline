# microsoft-defender

| Name | Description |
| ---- | ----------- |
| Windows Microsoft Defender Antivirus baseline Device | Microsoft Defender antivirus and antimalware settings. Note 'Local Admin Merge' is enabled. Apply to All Devices (optionally with filters) or Entra ID device groups. |
| Windows Microsoft Defender Antivirus exclusions Device | Folder path exclusions to support Intune clients. Exclusions may need to be updated in MDE as well. Apply to All Devices (optionally with filters) or Entra ID device groups. |
| Windows Microsoft Defender Antivirus update controls Device  | Configures Microsoft Defender update channels. Apply to All Devices (optionally with filters) or Entra ID device groups. |
