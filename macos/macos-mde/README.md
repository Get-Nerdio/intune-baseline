# macos-mde

| Name | Description |
| ---- | ----------- |
| [macOS][MDE] 2. Network Filter | Enables the Microsoft Defender for Endpoint network filter on macOS devices to allow monitoring and controlling of network traffic for threat detection and prevention. |
| [macOS][MDE] 3. Full Disk Access | Configures Microsoft Defender for Endpoint full disk access on macOS devices to enhance security by allowing comprehensive threat detection and response capabilities. |
| [macOS][MDE] 4. Background services | Configures Microsoft Defender for Endpoint background services on macOS devices to ensure continuous protection and threat detection. |
| [macOS][MDE] 5. Notifications  | Verifications are left on. This can be turned off using these instructions.  https://learn.microsoft.com/en-us/defender-endpoint/mac-install-with-intune#step-5-notifications |
| [macOS][MDE] 6. Accessibility settings  | Configures Microsoft Defender for Endpoint accessibility settings on macOS devices to enhance usability and ensure compliance with accessibility standards. |
| [macOS][MDE] 7. Bluetooth Permissions | macOS 14 (Sonoma) contains new privacy enhancements. Beginning with this version, by default, applications can't access Bluetooth without explicit consent. Microsoft Defender for Endpoint uses it if you configure Bluetooth policies for Device Control. |
| [macOS][MDE] 8. Microsoft AutoUpdate | The sample com.microsoft.autoupdate2.mobileconfig is set to Current Channel (Production). This profile is used to update the Microsoft Defender for Endpoint on macOS via Microsoft AutoUpdate (MAU). If you're deploying Microsoft Defender for Endpoint on macOS, you have the options to get an updated version of the application (Platform Update) that are in the different channels mentioned here: Beta (Insiders-Fast). Current channel (Preview, Insiders-Slow). Current channel (Production). For more information, see Deploy updates for Microsoft Defender for Endpoint on macOS. |
